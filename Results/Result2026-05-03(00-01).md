<h3 style="color: #2c5282;">C. Recommended Remediation Plan</h3>
<ol>
  <li><b>Establish an Idempotent Ingestion Pattern:</b> Replace append-only loads in Fabric with Delta Lake <code>MERGE</code> on unique primary business keys.</li>
  <li><b>Define a True Surrogate Key:</b> Re-engineer the view or pipeline to include transactional auto-incrementing surrogate keys (<code>HIST_ID</code> / <code>ROW_ID</code>) rather than non-unique natural keys.</li>
  <li><b>Audit Timestamp Formats & Precision:</b> Ensure the source extraction extracts microsecond-level datetime fields to prevent false multi-row collisions.</li>
  <li><b>Reconcile Transformation Mappings:</b> Document and confirm if translations on <code>COMMAND</code> and <code>TRANS</code> are expected warehouse dimension lookups.</li>
</ol>

### 🔹 Cell 24

#### 🎯 Logic & Purpose
Perform column-by-column mismatch profiling across matching composite keys to identify payload value discrepancies.
* **Data represented:** Count of mismatched rows per non-key attribute for rows sharing the same key combination.

#### 💻 Code
```python
# Logic/Purpose: Compare non-key attributes row-by-row on matching keys. 
# Data represented: For rows where keys match, count mismatches for each listed column. 

from pyspark.sql import functions as F 

keys = ["LOT", "DATE_TIME", "HISTORDER"] 

cols_to_compare = [ 
    "OPER", "OPERDESC", "OPERLONGDESC", "TRANS", 
    "HIST_REC", "MACHINE", "USERNAME", "COMMAND", "EMPID" 
] 

compare = df_Prod.alias("p").join(df_Fabric.alias("f"), keys) 

result = compare.agg(*[ 
    F.sum( 
        F.when( 
            F.coalesce(F.col(f"p.{c}"), F.lit("")) != 
            F.coalesce(F.col(f"f.{c}"), F.lit("")), 
            1 
        ).otherwise(0) 
    ).alias(f"{c}_MISMATCH") 
    for c in cols_to_compare 
]) 

result.show(truncate=False)
```

#### 📊 Result
```text
Single-row mismatch summary table containing: OPER_MISMATCH, TRANS_MISMATCH, HIST_REC_MISMATCH, MACHINE_MISMATCH, USERNAME_MISMATCH, COMMAND_MISMATCH, EMPID_MISMATCH.
```
